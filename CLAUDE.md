# Site — Apple-style

## Проект
Сайт в стиле apple.com. Репозиторий: cocame/site.
Главный файл: index.html

## Дизайн-стандарты (обязательно)
- Шрифт: SF Pro / -apple-system / BlinkMacSystemFont, sans-serif ТОЛЬКО
- Цвета: белый #ffffff, чёрный #1d1d1f, серый #6e6e73, акцент #0071e3
- border-radius: 12px (карточки), 980px (кнопки-пилюли как у Apple)
- Отступы: секции padding 120px 0, контент max-width 980px, центр
- Анимации: плавные, cubic-bezier(0.25, 0.1, 0.25, 1), 0.3-0.6s
- Изображения: всегда на всю ширину секции, без рамок
- Навигация: фиксированная, backdrop-filter blur(20px), полупрозрачная
- НЕТ: теням box-shadow с большим spread, ярким цветам, serif шрифтам

## Мобильная адаптивность
- Breakpoint: 768px
- Навигация сворачивается в бургер
- Текст масштабируется: h1 56px → 32px, h2 48px → 28px

## Позиционирование изображений на мобильных (ОБЯЗАТЕЛЬНО читать перед правкой img)

### Проблема: object-position не работает без overflow
`object-position` управляет только той частью изображения, которая выходит за пределы контейнера.
Если изображение **квадратное** (1:1) в **портретной** карточке (3:4 на мобильном):
- `object-fit: cover` масштабирует по высоте → изображение = высота карточки, горизонтальный обрезок
- Вертикального overflow нет → `object-position` по Y **не даёт эффекта**
- Всё изображение видно целиком, включая пустые области

### Решение: готовые CSS-классы (НЕ подбирать вручную)

Для карточек карусели используй готовые классы — значения уже вычислены и проверены:

| Где субъект | Класс на `<a>` | scale / origin |
|---|---|---|
| Нижняя половина фото | `carousel__card--sq-low` | 1.5 / center 80% |
| Нижняя треть фото | `carousel__card--sq-bottom` | 1.8 / center 85% |
| Центр фото, обрезать нельзя | `carousel__card--sq-fit` | 1.25 / center 96% |

**Важно про sq-fit:** для фото с субъектом в центре (например `sea-promo.png` — планшеты)
классы sq-low/sq-bottom НЕ подходят: они рассчитаны на низкий субъект и при таком зуме
режут края. Предел без обрезки для центрального субъекта — `scale 1.498`.

```html
<a href="#" class="carousel__card carousel__card--sq-bottom">
```

Никакой математики, никакого ручного подбора. Классы определены в index.html в блоке "Квадратные фото в портретных карточках".

### Когда object-position РАБОТАЕТ (не использовать transform)
- Карточка ландшафтная (16:9 на десктопе) + квадратное фото → вертикальный overflow есть
- В этом случае `object-position: center 65%` корректно сдвигает фокус вниз
